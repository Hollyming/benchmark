# Routine Step Ordering

Core question: can a system recover the correct order of a user or team workflow?

Required gold fields:

- ordered historical steps
- allowed reorderings or blocked reorderings
- future task with required sequence

Primary metrics:

- Routine Completion Score
- Policy Action Accuracy
- Evidence Faithfulness
