# Policy Update And Exception Handling

Core question: can a system distinguish a global policy update from a narrow exception?

Required gold fields:

- base policy evidence
- update or exception evidence
- scope constraints
- stale or obsolete evidence markers when applicable

Primary metrics:

- Exception Scope Accuracy
- Stale Policy Reuse Rate
- Overgeneralization Rate
- Boundary Violation Rate

Current status: partially represented in GHArchive probes but not claimed as a standalone covered task type in the current release.
