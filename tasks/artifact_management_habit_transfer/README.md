# Artifact Management Habit Transfer

Core question: can a system transfer file, screenshot, citation, naming, or source-recording habits to new artifacts?

Required gold fields:

- repeated artifact handling behavior
- naming or storage convention
- source-link or provenance requirement

Primary metrics:

- Routine Completion Score
- Evidence Faithfulness
- Policy Action Accuracy

Current status: planned for browser/files/docs workflows; not claimed by the current GHArchive release.
