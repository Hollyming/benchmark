# Tool Action Policy Alignment

Core question: can a system convert an induced policy into the correct future tool action?

Required gold fields:

- allowed actions
- forbidden actions
- required approval or clarification when applicable
- future probe with action-specific expected behavior

Primary metrics:

- Policy Action Accuracy
- Boundary Violation Rate
- Allowed/Forbidden Action F1
- `micro_boundary_action_recall`
