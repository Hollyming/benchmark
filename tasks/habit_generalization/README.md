# Cross-Day Habit Generalization

Core question: can a system infer a stable habit from behavior repeated across days or sessions?

Required gold fields:

- repeated evidence across time windows
- temporal scope
- exception or non-habit counterexample when available

Primary metrics:

- Policy Recall
- Condition Accuracy
- Future Utility AUC
- Stale Policy Reuse Rate

Current status: planned for multi-month or multi-domain releases; not claimed by the current GHArchive release.
