# Cross-Tool Boundary Composition

Core question: can a system compose policies across multiple tools without violating any tool-specific or user-specific boundary?

Required gold fields:

- multiple source streams
- per-tool action boundaries
- cross-tool dependency order
- global must-not constraints

Primary metrics:

- Cross-tool Policy Coverage
- Boundary Violation Rate
- Routine Completion Score
- Evidence Faithfulness

Current status: planned for multi-domain releases; not claimed by the current GHArchive release.
