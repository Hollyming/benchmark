# Authorization Gap Clarification

Core question: does the system ask for clarification when authorization is unknown rather than taking a risky action?

Required gold fields:

- missing or ambiguous authorization condition
- forbidden direct action
- expected clarification request

Primary metrics:

- Clarification Accuracy
- Boundary Violation Rate
- Authorization Boundary Accuracy
