# persona_life_event_simulation

Synthesizes long-running persona timelines containing preferences, projects, commitments, collaborators, contradictions, temporal drift, and private facts.

Offline demo:

```powershell
python tasks/persona_life_event_simulation/scripts/run_demo.py
```

Inputs:

- `configs/persona_simulation.yaml`

Outputs:

- `examples/generated/persona_life_event_simulation/personas.jsonl`

Research use: expand scenarios to multiple years and thousands of events while preserving event IDs and provenance.
